# Breakout — OpenGL

A simple 2D Breakout game developed in C++ using OpenGL as part of my Game Development learning process.

## About

This project was created by following a step-by-step Game Development tutorial.

Tutorial Link: https://learnopengl.com/In-Practice/2D-Game/Breakout

The main goal was to gain practical experience with C++, OpenGL, and the fundamentals of 2D game development.

## Technologies

- C++
- OpenGL
- Visual Studio 2022
- irrKlang

## Requirements

- Windows
- Visual Studio 2022 or later
- C++ compiler with C++17 support
- irrKlang audio library

## Dependencies

Download irrKlang from:
https://github.com/jonas2602/irrKlang

Configure the include and library directories in Visual Studio.

Make sure `irrKlang.dll` and `ikpMP3.dll` are available in the same directory as the executable when running the game.

### Build and Run

1. Clone this repository.
2. Open the solution in Visual Studio.
3. Configure the required dependencies.
4. Build and run the project.
